# Three different coach films

Same product. Three films that do not share a layout.

| Film        | File                         | What it is                                                                                                            |
| ----------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Kinetic     | [kinetic.mp4](./kinetic.mp4) | Full-bleed coach blue. Type only. No cards, no columns. Words slam, then the frame inverts to white for dark mode.    |
| The pass    | [pass.mp4](./pass.mp4)       | One camera move. Four full-frame color rooms slide past: blue, paper, black, rose. No cuts until GymOS.               |
| On the desk | [device.mp4](./device.mp4)   | A laptop on a warm table. The app changes inside the screen. The room stays cream. The machine leaves, then the name. |

Each is 18 seconds, 1920×1080, on the 120 BPM bed, with hits on the beats.

The coach is the subject in all three: onboard, draft the week, watch the weight, set the workspace. Diet is one onboarding step.
