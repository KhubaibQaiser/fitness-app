# Runbooks

Every alert must have a runbook here before it ships (symptom → diagnosis → remediation → escalation). An alarm without a documented response is noise that trains people to ignore alarms.

Planned set (created alongside the alerts that reference them): `down`, `error-spike`, `neon-cu-exhausted`, `generation-failures`, `allergen-rejection`, `disk-full`, `cert-renewal`, `restore-from-backup`, `email-otp`.
